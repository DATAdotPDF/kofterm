; Digite "?" e o que você quer fazer, por exemplo:  ? instalar o htop
; O KofTerm procura a receita mais parecida e mostra o comando em cinza. TAB coloca o comando
; na linha; nada roda sozinho. O índice (F2) explica cada parte.
;
; Formato:  # nome   ? jeito de pedir (vários)   $ comando   % comando no shell de root   > explicação
; {nome} é uma lacuna preenchida com as palavras do pedido. Comandos que apagam usam -i
; (perguntam antes). Para contribuir: comandos que funcionam no Debian, Ubuntu e Kali.
; A linha % é opcional: sem ela, quem já é root (sudo -i) recebe o comando sem "sudo"; "% -" esconde a receita.

? conferir hashes

# codificar base64
? codificar {texto} em base64
? base64 de {texto}
$ echo -n "{texto}" | base64
> Codifica {texto} em Base64 (não é criptografia).

# decodificar base64
? decodificar base64 {texto}
? decodificar {texto}
$ echo "{texto}" | base64 -d
> Volta o Base64 {texto} ao original.

# gerar senha aleatória
? gerar senha aleatória
? criar senha forte
$ openssl rand -base64 16
> Uma senha aleatória de 16 bytes em Base64.
