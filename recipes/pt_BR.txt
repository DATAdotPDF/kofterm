; Digite "?" e o que você quer fazer, por exemplo:  ? instalar o htop
; O KofTerm procura a receita mais parecida e mostra o comando em cinza. TAB coloca o comando
; na linha; nada roda sozinho. O índice (F2) explica cada parte.
;
; Formato:  # nome   ? jeito de pedir (vários)   $ comando   > explicação
; {nome} é uma lacuna preenchida com as palavras do pedido. Comandos que apagam usam -i
; (perguntam antes). Para contribuir: comandos que funcionam no Debian, Ubuntu e Kali.

; ───────────── Programas ─────────────

# instalar programa
? instalar {pacote}
? instalar o programa {pacote}
? baixar o programa {pacote}
? quero o {pacote}
? como instalo {pacote}
$ sudo apt update && sudo apt install -y {pacote}
> Atualiza a lista de pacotes e instala {pacote}. Pede a sua senha (sudo).

# remover programa
? remover {pacote}
? desinstalar {pacote}
? tirar o programa {pacote}
