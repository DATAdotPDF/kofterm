; KofTerm — recipes for the "?" mode (English)
; Text written by the KofTerm project, GPLv3 license. Same recipes, in the same order, as pt_BR.txt.
;
; Type "?" and what you want to do, for example:  ? install htop
; KofTerm looks for the closest recipe and shows the command in grey. TAB puts the command
; on the line; nothing runs by itself. The index (F2) explains each part.
;
; Format:  # name   ? way of asking (several)   $ command   % command in a root shell   > explanation
; {name} is a gap filled with the words of the request. Commands that delete use -i
; (they ask first). To contribute: commands that work on Debian, Ubuntu and Kali.
; The % line is optional: without it, someone who is already root (sudo -i) gets the command without "sudo"; "% -" hides the recipe.

? running services
? see the active services

$ systemctl list-units --type=service --state=running

? turn on service {service} at boot
? start {service} with the system
