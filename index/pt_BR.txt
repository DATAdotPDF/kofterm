# ls
> Lista os arquivos e pastas de um diretório.
- -l | Formato longo: permissões, dono, grupo, tamanho e data de cada item.
- -a, --all | Mostra também os itens ocultos (os que começam com ponto, como .bashrc).
- -A | Como -a, mas sem as entradas . (pasta atual) e .. (pasta de cima).
- -d | Mostra a própria pasta, não o que tem dentro dela. Útil com -l para ver as permissões de uma pasta.
- -h | Tamanhos legíveis (K, M, G) em vez de bytes. Funciona junto com -l.
- -t | Ordena pela data de modificação, mais recentes primeiro.
- -r | Inverte a ordem.
- -S | Ordena pelo tamanho, maiores primeiro.
- -R | Entra nas subpastas (recursivo).
- -1 | Um item por linha.
$ ls -la | Tudo, inclusive ocultos, em formato longo.
$ ls -lh | Formato longo com tamanhos em K, M, G.
$ ls -ld /etc | Permissões da própria pasta /etc.
$ ls -lt | Os modificados por último aparecem primeiro.
@ https://ss64.com/bash/ls.html
@ https://man7.org/linux/man-pages/man1/ls.1.html

> Muda a pasta atual.
- - | Volta para a pasta em que você estava antes (cd -).

$ cd .. | Sobe uma pasta.
$ cd ~ | Vai para a sua pasta pessoal (também funciona só cd).
$ cd - | Volta para a pasta anterior.
@ https://ss64.com/bash/cd.html
@ https://www.gnu.org/software/bash/manual/bash.html#Bourne-Shell-Builtins

# cp

- -p | Mantém permissões, dono e datas.
$ cp a.txt b.txt | Copia a.txt para b.txt.

# rm
> Apaga arquivos e pastas. Não existe lixeira: o que é apagado some.
- -r | Apaga pastas com tudo o que tem dentro (recursivo).
- -f | Não pergunta nada e não reclama de arquivos que não existem. Cuidado.
- -i | Pergunta antes de apagar cada arquivo. Bom para quem está começando.
- -v | Mostra cada item apagado.
$ rm notas.txt | Apaga um arquivo.
$ rm -ri pasta | Apaga a pasta, perguntando item por item.
@ https://ss64.com/bash/rm.html
@ https://man7.org/linux/man-pages/man1/rm.1.html

# grep
> Procura um texto dentro de arquivos ou da saída de outro comando.
- -i | Ignora maiúsculas e minúsculas.
- -r | Procura em todos os arquivos das subpastas.
- -n | Mostra o número da linha de cada resultado.
- -v | Inverte: mostra as linhas que NÃO têm o texto.
- -l | Mostra só o nome dos arquivos que têm o texto.
- -c | Conta quantas linhas têm o texto.
- -w | Só palavras inteiras.
- -E | Usa expressões regulares estendidas (|, +, ? sem barra invertida).
$ grep -rn "TODO" . | Procura TODO em todos os arquivos, com o número da linha.
$ ps aux | grep firefox | Filtra a lista de processos.
@ https://ss64.com/bash/grep.html
@ https://man7.org/linux/man-pages/man1/grep.1.html

# find
! findutils
> Procura arquivos e pastas pelo nome, tipo, tamanho ou data.
- -name | Pelo nome. Use aspas com curingas: -name "*.txt".
- -iname | Pelo nome, sem diferenciar maiúsculas.
- -type | Pelo tipo: f arquivo, d pasta, l link.
- -size | Pelo tamanho: +100M é maior que 100 MB.
- -mtime | Pela data: -7 é modificado nos últimos 7 dias.
- -maxdepth | Até quantos níveis de subpastas descer.
$ find . -name "*.log" | Todos os .log a partir da pasta atual.
$ find /home -type d -name kof | Pastas chamadas kof.
@ https://ss64.com/bash/find.html
@ https://man7.org/linux/man-pages/man1/find.1.html

# sudo
! sudo
> "Super-user do": roda UM comando como administrador (root). Pede a SUA senha, não a do root, e só funciona se você estiver no grupo sudo. Tudo fica registrado no journal.
- -i | Abre um shell de root (o prompt muda de $ para #). Digite exit para voltar ao seu usuário.
- -s | Shell de root, mas continua na pasta atual.
- -l | Lista o que você tem permissão de rodar com sudo.
- -k | Esquece a senha digitada; a próxima vez vai pedir de novo.
- -u | Roda como outro usuário: sudo -u nome comando.
$ sudo -l | Confere se você pode usar sudo.
$ sudo -i | Vira root até digitar exit.
$ sudo apt update | Atualiza a lista de pacotes como administrador.
$ sudo !! | Repete o último comando com sudo (quando deu "Permission denied").
@ https://ss64.com/bash/sudo.html
@ https://man7.org/linux/man-pages/man8/sudo.8.html

# ping

# ip
! iproute2
> Mostra e configura a rede (substitui o antigo ifconfig). Os subcomandos podem ser abreviados: ip a = ip address.
$ ip a | Endereços IP de cada placa de rede (inet = IPv4, inet6 = IPv6).
$ ip r | Tabela de rotas: "default via" é o gateway.
$ ip link | Placas de rede, estado (UP/DOWN) e endereço MAC.
$ ip neigh | Tabela ARP: os vizinhos da rede local e seus MACs.
@ https://man7.org/linux/man-pages/man8/ip.8.html

# ip a
> Mostra os endereços de cada interface. Procure "inet" (IPv4 com a máscara em /24, /16...) e "state UP".
$ ip -br a | Versão resumida: uma linha por interface.
$ ip a show eth0 | Só a interface eth0.
@ https://man7.org/linux/man-pages/man8/ip-address.8.html

# ip r
> Mostra a tabela de rotas. A linha "default via X" diz qual é o gateway (o roteador da sua rede).
$ ip r | Todas as rotas.
$ ip r get 8.8.8.8 | Por qual interface e gateway um destino sairia.
@ https://man7.org/linux/man-pages/man8/ip-route.8.html

# ip link
> Mostra as interfaces de rede, se estão ligadas (UP) e o endereço MAC (link/ether).
$ ip link | Lista as interfaces.
$ sudo ip link set eth0 down | Desliga a interface eth0 (up liga de novo).
@ https://man7.org/linux/man-pages/man8/ip-link.8.html

# ip neigh
> Tabela ARP/vizinhos: quais IPs da rede local já foram vistos e qual o MAC de cada um. Equivale ao antigo "arp -a".
$ ip neigh | Lista os vizinhos.
@ https://man7.org/linux/man-pages/man8/ip-neighbour.8.html

> O "buraco negro": tudo que vai para lá some.

$ find / -name '*.conf' 2>/dev/null | Busca sem a lista de "Permissão negada".
@ https://manpages.debian.org/null.4

# ~/.bashrc
> Configuração do seu bash, lida a cada terminal novo: aliases, PATH, prompt. Depois de editar: source ~/.bashrc.
$ nano ~/.bashrc | Edita.
$ source ~/.bashrc | Aplica sem abrir outro terminal.
@ https://www.gnu.org/software/bash/manual/bash.html#Bash-Startup-Files

# ~/.bash_history
> Os comandos que você já digitou (salvos ao sair do shell).
$ tail -20 ~/.bash_history | Os últimos 20.
@ https://www.gnu.org/software/bash/manual/bash.html#Bash-History-Facilities

# ~/.ssh
> Suas chaves SSH e configurações. A pasta deve ser 700 e a chave privada 600, senão o ssh recusa.
$ ls -la ~/.ssh | Mostra as chaves.
$ chmod 700 ~/.ssh && chmod 600 ~/.ssh/id_ed25519 | Corrige as permissões.
@ https://manpages.debian.org/ssh

# ~/.ssh/authorized_keys
> Chaves públicas autorizadas a entrar na SUA conta por SSH. Uma por linha. Confira de vez em quando.
$ cat ~/.ssh/authorized_keys | Quem pode entrar sem senha.
@ https://manpages.debian.org/sshd
